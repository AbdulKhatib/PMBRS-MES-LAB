# Evidence

This folder is the intended home for supporting evidence referenced throughout `/docs` and `/testing` — screenshots of pipeline runs, AWS console confirmations, terminal output, and similar artifacts backing up the claims made in this repository's documentation.

As of the current state of this project, evidence has been captured and reviewed throughout the build (see references to specific screenshots in `docs/` and `testing/`), but has not yet been organized and uploaded into this folder in a structured way. This is a known, acknowledged gap — not an oversight being hidden.

## Planned structure

```
evidence/
├── screenshots/       UI confirmations (AWS console, IIS Manager, terminal output)
├── deployment-logs/    Captured deployment.log snapshots from key pipeline runs
└── test-results/       Query outputs, pipeline pass/fail transcripts
```
